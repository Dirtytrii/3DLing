# 生日礼物：完整加载与动效细化（2026-10-16）

## 用户反馈与范围

用户确认整体视觉没有问题，希望解决进入主页后下滑仍未加载完的问题，并细化加载画面、字体和整体动效。继续支持 1440×900、1440×800、1280×720 电脑视口；保留原照片、玩偶、布景构图、回忆文案与待填写的信件。

## 本轮设计约定

页面类型为 content / 私人回忆礼物。沿用已获肯定的十段顺序体验与左右构图；不新增移动端布局，也不引入滚动接管或动画运行库。

- 加载页沿用暮紫、暖粉、奶油金色：闭合礼物与细星轨居中，云朵框住下缘。界面文字和真实进度由 HTML 绘制，生成图片不包含字或进度。
- 进度只来自真实完成的图片加载/解码、字体与玩偶纹理准备；全部完成后退场。失败停留并提供重试；不以超时兜底放行。
- 标题用本地 Noto Serif SC，正文用本地 Noto Sans SC；统一 400–600 字重、行距、标点与段落宽度。保留 Ling 的拉丁字标。
- 背景、玩偶使用一致的 800ms 过渡；标题、正文、照片轻微错峰，动画只处理透明度与位移。浏览器原生滚动，长信/照片墙保留自然阅读。
- 按钮、图片切换、目录反馈采用同一套缓动；尊重系统减少动态效果设置。

字体层级：标题 64–106px / 500，回忆副标题 24–33px / 500，正文 16–18px / 400，封面副标题 20–25px，信件 21px 衬线 / 2.1 倍行高；控制文字 15–18px。小高度视口沿用原布局收紧至既有 720px 断点。颜色、间距和边角延续生日主题语义 token。

状态：准备阶段滚动锁与 `inert` 同时生效；进度完成才淡出；失败展示友好重试。按钮 hover 上浮 3px、按压收回；键盘轮廓、吹灭中禁用和空信提示保持可见。背景/玩偶 800ms、文字 700ms（0/60/110/160ms 错峰）、相册交叉淡化 450ms、控件反馈 240ms、加载退场 700ms。减少动态效果时过渡即刻结束且取消循环动画。

## 素材与字体来源

概念图由 imagegen 生成：加载页 `exec-1d6b915f-0946-42e4-9bc3-7999839d2f51.png`；字体细化参考 `exec-edd3a29e-fb18-4bc8-97d3-1b5a81988bc0.png`。参考中的玩偶重绘不进入产品，继续使用原 PNG 的无损衍生图。生产加载布景 `public/gift/loading-dream.png` 由加载概念图去除全部 UI 得到。

`npm run optimize:gift` 生成 WebP 与 `src/data/optimizedAssets.json`，原 PNG 不变；玩偶采用无损压缩，布景质量 90。文件名包含内容哈希以避免更新时缓存混用。

字体来自 [Google Fonts 官方仓库](https://github.com/google/fonts)，固定提交 `1d0e46c7933245c8180fe83e47917961c913bbdb` 的 `ofl/notoserifsc/NotoSerifSC[wght].ttf` 和 `ofl/notosanssc/NotoSansSC[wght].ttf`。OFL 1.1 授权随网站放在 `public/fonts/OFL-NotoSerifSC.txt` 与 `OFL-NotoSansSC.txt`。

字体原文件仅下载到 `tmp/font-sources`。安装 `fonttools[woff]==4.60.1` 后，运行 `python scripts/subset-gift-fonts.py --source-dir tmp/font-sources` 生成本地 WOFF2。裁剪字符来自项目源码和当前信件，**不向外部发送信件或任何私人文字**。以后放入信件后重新生成字体；未覆盖字符仍有系统字体兜底。
