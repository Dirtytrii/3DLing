# 信封、信纸与长信聚焦（2026-10-16）

## 2026-10-17 逐行墨色阅读（最新设计）

最新用户反馈：“这个效果也还是一般呢 好好设计一下”。上一版只调整段落柔光，阅读反馈仍不够具体；本次重做聚焦交互层，而不改用户已经认可的信封、纸张、标题、正文、排版与背景。默认开启、无右上角控件、手动滚动保持不变。

设计合同：content / 私人长信；读到哪一行，哪一行的真实文字墨色加深，附近行渐次回到清晰的低对比墨色。删除纸面椭圆光斑；在正文左侧内页边留白用 18px 四角小星芒标记当前行，不使用竖线、下划线、标签、计数或控件。字体 20/21px、行距 2.15、容器 780px 及所有原字不变；正文只保留一份可选择复制的原生文本，字重、字号、透明度和清晰度不变。墨色 `#432d49` / `#75616e`，星芒复用 `--letter-gold`。

交互合同：缓存原生 Range 行矩形，滚动参考视口 48% 的阅读线；行边界设置约 0.16 行高的滞回区，避免小幅滚动来回切换。鼠标同一行停留 160ms 后切换，滚动优先并取消待切换任务；仅文字内的墨色渐变及边栏星芒约 540ms 过渡。选字时隐藏星芒、全文恢复正常墨色，减少动态效果时立即切换，离开/隐藏时取消任务，无空闲 RAF 循环。单个超长段落也支持逐行聚焦。

## 设计与实现计划

- 保留现有暮紫云朵背景、Ling 字标、目录及前后导航，只调整信件表面。封面标题仍为“给你的一封信”，按钮仍为“打开信”。
- 信封放大为约 720×408px 的主体，采用棉纸纤维、薄金折线、粉色缎带、真实星形封蜡；拆为原生翻盖、口袋、信纸及独立封蜡层。封蜡先松开、翻盖打开、抽纸、信纸展开，约两秒内完成；可直接读信，离开中断恢复 sealed。
- 信纸保持约 780px 宽，增加自然边缘、层叠厚度和细金线；纹理与边缘分别处理以承受任意正文长度，不拉长装饰图。正文约 20–21px，衬线，行距 2.1–2.2，段间 1.6em，正文宽度约 580px。
- 信件标题约 44–50px，纸面暮紫墨色 `#432d49`；纸张延续暖象牙色，金线与标记使用柔和古金色。其余字至少保持可读对比，不采用失焦模糊。
- 多段正文可用“聚焦阅读”开关：手动滚动时焦点落在视口中部附近的段落，鼠标实际移入其他段落时切换；重新滚动立即恢复按滚动位置聚焦。只变更当前/前一段属性与侧边标记，事件按需 rAF 合并，无空闲循环或逐帧 React 更新。
- 选中文字时恢复完整阅读对比，暂停鼠标聚焦干扰；关闭效果则全文统一墨色。键盘滚动、放大、窗口改变仍可阅读；减少动态效果时立即显示状态、不移动聚焦灯光。
- 桌面验收 1440×900、1440×800、1280×720。小高度收紧信封尺寸及外间距；长文自然滚动，页尾链接在正文之后，不与正文重叠。
- 新图片纳入现有 WebP 生成与完整加载清单；后续真实正文加入后按既有脚本重新生成本地字体。
