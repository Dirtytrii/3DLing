# 信封、信纸与长信聚焦（2026-10-16）

## 范围与明确选择

用户认为当前整体效果不错，要求信封与信纸更精致，并支持一页放不下的长信。用户明确选择“只做聚焦，保留手动滚动”。页面类型是 content / 个人信件；继续使用原生页面滚动，信纸随正文自然长高，正文原文待提供，不代写、不做自动滚动。

## 设计与实现计划

- 保留现有暮紫云朵背景、Ling 字标、目录及前后导航，只调整信件表面。封面标题仍为“给你的一封信”，按钮仍为“打开信”。
- 信封放大为约 720×408px 的主体，采用棉纸纤维、薄金折线、粉色缎带、真实星形封蜡；拆为原生翻盖、口袋、信纸及独立封蜡层。封蜡先松开、翻盖打开、抽纸、信纸展开，约两秒内完成；可直接读信，离开中断恢复 sealed。
- 信纸保持约 780px 宽，增加自然边缘、层叠厚度和细金线；纹理与边缘分别处理以承受任意正文长度，不拉长装饰图。正文约 20–21px，衬线，行距 2.1–2.2，段间 1.6em，正文宽度约 580px。
- 信件标题约 44–50px，纸面暮紫墨色 `#432d49`；纸张延续暖象牙色，金线与标记使用柔和古金色。其余字至少保持可读对比，不采用失焦模糊。
- 多段正文可用“聚焦阅读”开关：手动滚动时焦点落在视口中部附近的段落，鼠标实际移入其他段落时切换；重新滚动立即恢复按滚动位置聚焦。只变更当前/前一段属性与侧边标记，事件按需 rAF 合并，无空闲循环或逐帧 React 更新。
- 选中文字时恢复完整阅读对比，暂停鼠标聚焦干扰；关闭效果则全文统一墨色。键盘滚动、放大、窗口改变仍可阅读；减少动态效果时立即显示状态、不移动聚焦灯光。
- 桌面验收 1440×900、1440×800、1280×720。小高度收紧信封尺寸及外间距；长文自然滚动，页尾链接在正文之后，不与正文重叠。
- 新图片纳入现有 WebP 生成与完整加载清单；后续真实正文加入后按既有脚本重新生成本地字体。

## 验收口径

IAB 先检查封面→开信→读信，随后三尺寸可重复截图与网络/交互验证。需要逐项比对封面构图、纸张材质、标题与正文、留白、图层、动画关键帧、聚焦对比和页尾位置。

长信使用临时请求替换注入 24 段样文，另测一个长段落、空白段、原有换行与字面 HTML；正式 `gift.letter.body` 保持空。检查滚动换焦、悬停换焦、滚动优先、离开悬停、选中文字、开关、减少动态效果、原生滚动未被自动改变，以及离开后的监听/rAF 清理。

## 已交付实现

- 四张独立生产图及哈希 WebP：信封 `envelope-stationery`、封蜡 `star-wax-seal`、边框 `letter-stationery`、匹配纹理 `letter-cotton-texture`。尺寸、生成源与文件体积见 `docs/gift-assets.md`；均由内置 imagegen 生成，无外部素材下载。四张图全部进入现有完整加载闸门。
- `LetterSection.tsx` / `styles.css`：封蜡 450ms 松开，翻盖延迟 160ms 后旋转，抽纸及新纸面接续，2100ms 进入 reading；小高度信封为 600px，正常高度 720px。纸边九宫格与中心纹理分别处理。
- `useReadingFocus.ts`：滚动、鼠标、选择、窗口变化及清理；只有实际可见的多段信件才监听。字号 20–21px、行距 2.15；当前段 `#432d49`，邻段 `#725d65`，邻段保持清晰。柔光、细金侧标、颜色渐变，不模糊文本。
- `App.tsx`：IntersectionObserver 保存当前相交 section 集合。回调仅包含发生变化的 entry，旧实现可能在前一幕离开后遗漏持续可见的长信，导致目录还标生日；本轮复现并修正。纸面可见性独立观察，避免键盘将开关带入视野时阅读效果仍受上一幕状态限制。
- 字体脚本收录聚焦控件与明确的测试样文字符，重新生成 514 字符本地子集；正文原文仍为空，未把 QA 样文写进生产配置。
